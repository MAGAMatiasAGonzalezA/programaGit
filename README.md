#  🧱 Trabajo Práctico Final

 La aplicación esta pensada para el manejo interno de la cocina, donde el uso de las recetas consume la matería prima registrada en el inventario y retorna las porciones correspondientes a cada receta utilizada, registrandolas con fecha actualizada para futuras notificaciones de su estado (apto o no para consumo) 

## 💡 Idea y objetivo de la aplicación

- Manejo de inventario de cocina
- Guardar, modificar o eliminar recetas
- El uso de las recetas deben consumir la matería prima correspondiente y cargar con fecha actual las porciones producidas
- Consumo de porciones por venta u otros
- Registros automáticos de modificaciones en las recetas, con pendiente de confirmación de sustitución de la receta actual (cambio realizado y resultados finales obtenidos)
- Niveles de acceso para ver, modificar o eliminar por medio de usuarios
- Inicio por defecto, que se pueda ver determinados detalles de las recetas y las porciones con foto (vista completa con inicio de sesión según nivel de acceso)
